# AI Interview Agent

An AI-powered interview system that simulates real technical interviews and evaluates candidates with intelligent feedback.

## 🚀 Features
- Role-based dynamic question generation
- AI-powered answer evaluation
- Real-time scoring and feedback
- Final hiring verdict (Hire / Maybe / Reject)
- Performance summary with improvement tips

## 🧠 How It Works
1. User selects a role (e.g. Frontend Developer)
2. AI generates tailored interview questions
3. User answers questions
4. AI evaluates responses based on:
   - correctness
   - clarity
   - depth
5. System generates final verdict and feedback

## 🛠 Tech Stack
- React (Vite)
- Tailwind CSS
- Node.js / Express
- Gemini API
